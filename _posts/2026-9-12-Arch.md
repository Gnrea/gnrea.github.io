# Linux Start
it has been an hour already (4:19 PM) and I completed about 5 mins worth of tasks. We've verified our USB works and that our file hasn't been tampered with.

I've already changed the BIOS settings on my device to prioritize USB's above default boot, but if you need assistance.
1. Power off the PC and spam the esc/f12/del (it depends on manufacturer and device)
2. go into bios
3. sometimes you will need to turn off Secure Boot (added to things to look into)
4. Edit Boot Order, I prefer to have USB HDD as my top priority and then the OSes I use afterwards. (This means if a USB plugged in, boot from that first. Plus Ventoy you get more options)
5. Save and close those changes

Now we finally booted into the arch install and got into the arch root after using the Ventoy USB at 4:32 PM!
The first thing that appears is a virtual console andd Zsh shell where the command line says "root@archiso" and we start in the home directory.
The official guide tells us that the US console keymap is selected as default, but this can be changed with the "loadkeys" command.
The full list is available by typing "localctl list-keymaps". The guide also mentions that you can use any font downloaded, so I can't wait to use the worst ones possible.

The most important thing we have to do now is 
1. "cat /sys/firmware/efi/fw_platform_size" this checks the boot In my case I have a x64 system so the output was 64.
2. "rfkill" shows us if our hardware is blocked by kernel so we can set up network connection. My output was "unblocked" for my NICs and bluetooth adapters.
3. "iwctl"
In this case I have a wireless connection, so I will be using the command and tool "iwctl".
3. After typing iwctl, I typed the command "device list" to grab the device name.
I find it fun using hidden SSID's for my network devices so I had to specify hidden in the next step.
4.station (device name from device list) connect-hidden (SSID/network name)
5. After typing that command I was prompted for a password and after I typed it, i had no output so I assumed it worked
6. I checked my networks with the command "known-networks list" inside fo the "iwctl" menu.
7. after connect my device to the network, I used "ctrl + d" to leave the "iwctl" menu.
Now I need to use NTP to update the system time and keep it accurate.
The guide told me I could do this by using "timedatectl" to check the default values from "systemd-timesyncd"
Using 'timedatectl -help" I found out that I can set a timezone using "timedatectl set-timezone [Country/City]"
