# Linux Start
it has been an hour already (4:19 PM) and I completed about 5 mins worth of tasks. We've verified our USB works and that our file hasn't been tampered with.

I've already changed the BIOS settings on my device to prioritize USB's above default boot, but if you need assistance.
1. Power off the PC and spam the esc/f12/del (it depends on manufacturer and device)
2. go into bios
3. sometimes you will need to turn off Secure Boot (added to things to look into)
4. Edit Boot Order, I prefer to have USB HDD as my top priority and then the OSes I use afterwards. (This means if a USB plugged in, boot from that first. Plus Ventoy you get more options)
5. Save and close those changes

Now we finally booted into the arch install and got into the arch root after using the Ventoy USB at 4:32 PM!
The first thing that appears is a virtual console andd Zsh shell where the command line says "root@archiso" and we start in the home directory.
The official guide tells us that the US console keymap is selected as default, but this can be changed with the "loadkeys" command.
The full list is available by typing "localctl list-keymaps". The guide also mentions that you can use any font downloaded, so I can't wait to use the worst ones possible.

The most important thing we have to do now is 1. check the boot mode by running "# cat /sys/firmware/efi/fw_platform_size".
In my case I have a x64 system so the output was 64.
2. set up network connection. running "rfkill" shows us if our hardware is blocked by the kernel and my output was "unblocked" for my NICs and bluetooth adapters.
In this case I have a wireless connection, so I will be using the command and tool "iwctl".
3. After typing iwctl, I typed the command "device list" to grab the device name.
I find it fun using hidden SSID's for my network devices so I had to specify hidden in the next step.
4.station (device name from device list) connect-hidden (SSID/network name)
5. After typing that command I was prompted for a password and after I typed it, i had no output so I assumed it worked
6. I checked my networks with the command "known-networks list" inside fo the "iwctl" menu.
7. after connect my device to the network, I used "ctrl + d" to leave the "iwctl" menu.
Now I need to use NTP to update the system time and keep it accurate.
The guide told me I could do this by using "timedatectl" to check the default values from "systemd-timesyncd"
Using 'timedatectl -help" I found out that I can set a timezone using "timedatectl set-timezone [Country/City]"
8. ping [destionation], I forgot to test the connectivity before messing with NTP, but ping works fine so I did it correctly

# Disk Partitioning
Its now 5:16 PM and I see the first tool I've used before which is fdisk. I've almost bricked my USB at least 7 times using it, but its "experience."
1. "fdisk -l" we're listing our current block devices or if you want to see the tree diagram you can use "lsblk".
I don't know how useful it is, but I've learned my SSD says its physical sector size is 512 bytes, but there's a new link that I want to explore in the "look into" seciton.
"lsblk -td" could be lying to me given the Note in "advanced format" resource, but I think it is what it needs for it's optimal logical sector size.
typing "cat /sys/class/block/(drive)/queue/physical_block size" and "cat /sys/class/block/(drive)/queue/logical_block size" both gave me 512, so I am going to trust it. now it's 5:54 PM so I might take a break and come back tmr so I can think through partitioning more and get some food. Started up again at 10:30 PM
2. "fdisk /dev/(drive that has size of 400+ GB and says Linux filesystem)"
3. in the fdisk menu I typed "m" for more info
4. Then i typed "F" and found 400+ GB of free unpartitioned space so I know I am in the right spot
5. "g" to create a GPT partition table
6. "n" for a new partion
7. "1" for partition 1 also default
8. "2048" for the start byte also default
9. "+1G" for 1 GiB partition for "/boot" Also the G is for GiB not to be confused with GB
10. "n", 2nd new partition
11. "2", also default
12. "2099200" also default
13. "+4G" for 4GiB for "swap" partition
14. "3" also default
15. "10487808" also default
16. "+50G" 50 Gibibytes for root or / that runs everything. I Didn't use more so I can add more storage later and I wanted to save space for dual boot.
17. "p" to print out the current partition table and double check my values.
18. "v" to validate and I got "No errors detected."
19. "i" grab info about partition
20. "1" show me info about partition 1 that we want to be /boot
21. "i"
22. "2" show me info about partition 2 that we want to be /swap
23. "i"
24. "3" show me info about partition 3 that we want to be /
25. "w" this confirms our previous changes and writes the changes to our disk on reboot or when we run a command to update the kernel.
Since we ran the info we have our partition names in the chat history and we can easily reference them so we can start formatting them
